# 🎵 Spotifia

A Spotify-inspired interactive puzzle website combining **music, puzzles, and storytelling**, created as a small personal experience for someone special.

## ✨ Features

* 🎧 Spotify-inspired dark UI
* 🧩 Multiple interactive puzzles
* 🔐 Unlockable albums and hidden content
* 💾 Persistent progress using LocalStorage
* 🎨 Custom album and artist artwork
* 🎵 Interactive music-player interface
* ❤️ Multi-stage final experience

## 🧩 Puzzle Albums

* **Love** 💗: Playlist + passcode puzzle
* **Midnight Sun** 🌙: Word, shadow, and codeword puzzles
* **BLR** 🌆: Math, key, and cipher puzzles
* **<3** ❤️: Binary / eight-segment display puzzle

Progression is tracked through unlocked, visited, and discovered albums.

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES Modules)
* SVG
* LocalStorage
* Python HTTP Server

## 🚀 Run Locally

```bash
git clone <your-repository-url>
cd Spotifia
npm run dev
```

Then open:

```text
http://localhost:4173
```
